# Indonesian campus directory

Source is the public Pusdatin Kemdiktisaintek dataset [Data Jumlah Perguruan Tinggi dan Status Akreditasi Pada Tahun 2025](https://data.kemdiktisaintek.go.id/dataset/data-jumlah-perguruan-tinggi-dan-status-akreditasi-pada-tahun-2025).

The JSON contains 3,568 entries from the published XLSX. Each row contains the trimmed NPSN, institution name, and city or regency. Codes are stored as strings to preserve leading zeroes. The index covers the institutions in that edition of the dataset. Unmatched queries can still be sent to the live Kemendikdasmen directory.
