## Purpose

Lets users create and work on an interactive multiple-choice quiz directly inside the assistant chat page by typing `/kuis`, with questions generated by AI from the session's conversation topics and any mentioned notes.

## ADDED Requirements

### Requirement: Trigger kuis via command /kuis
The system SHALL treat a composer submit of `/kuis` (case-insensitive) as a request to open the quiz popup, and SHALL NOT send it as a regular message to the AI.

#### Scenario: Command /kuis membuka popup kuis
- **WHEN** user types `/kuis` in the chat composer and submits
- **THEN** the quiz popup opens and no assistant reply is generated for that input

#### Scenario: Sesi tanpa materi
- **WHEN** user submits `/kuis` in a session that has no messages
- **THEN** the quiz popup opens showing an informational message that there is no material yet, and no AI generation call is made

### Requirement: Kuis digenerate dari topik sesi dan catatan mention
The system SHALL generate multiple-choice quiz questions from the conversation content of the session plus the content of notes mentioned (`@`) in the session, and SHALL let the user choose the question count (5, 8, or 10) before generation, with questions written in Indonesian.

#### Scenario: Generate otomatis saat command
- **WHEN** user submits `/kuis` in a session with messages
- **THEN** the popup opens and immediately starts generating 5 questions, showing a loading state until they are ready

#### Scenario: Sumber materi gabungan
- **WHEN** the session contains messages and mentions of one or more notes
- **THEN** the generation context includes both the session messages and the content of the mentioned notes

### Requirement: Pengalaman mengerjakan kuis interaktif
The system SHALL let the user answer each question, submit the quiz, and see the score plus per-question explanations afterwards, and SHALL allow regenerating a new set of questions.

#### Scenario: Mengerjakan dan melihat skor
- **WHEN** user selects answers and submits the quiz
- **THEN** the popup shows the score (correct/total) and each question with its explanation

#### Scenario: Regenerasi dengan pilihan jumlah soal
- **WHEN** user taps "Ulangi" in the quiz popup
- **THEN** the popup shows the question count options (5, 8, or 10); when the user confirms, the system generates that many new questions and resets the answers

### Requirement: Kegagalan generation ditangani
The system SHALL show an error message inside the popup when generation fails, without closing the popup, and SHALL let the user retry.

#### Scenario: Generation gagal
- **WHEN** the AI fails to produce valid questions
- **THEN** the popup displays an error message and a retry option, and remains open

### Requirement: Kuis mobile-friendly
The quiz popup SHALL be fully usable on mobile viewports: rendered as a bottom sheet on small screens, with touch targets of at least 44px, respect for the safe-area inset at the bottom, and internal scrolling for long content.

#### Scenario: Popup di layar sempit
- **WHEN** the quiz popup is open on a mobile-width viewport
- **THEN** the popup anchors to the bottom of the screen, all interactive controls are at least 44px tall, and long question lists scroll within the popup without page overflow
