## Purpose

Lets users create and practice flashcards directly inside the assistant chat page by typing `/card`, with cards generated by AI from the session's conversation topics and any mentioned notes.

## ADDED Requirements

### Requirement: Trigger flashcard via command /card
The system SHALL treat a composer submit of `/card` (case-insensitive) as a request to open the flashcards popup, and SHALL NOT send it as a regular message to the AI.

#### Scenario: Command /card membuka popup flashcard
- **WHEN** user types `/card` in the chat composer and submits
- **THEN** the flashcards popup opens and no assistant reply is generated for that input

#### Scenario: Sesi tanpa materi
- **WHEN** user submits `/card` in a session that has no messages
- **THEN** the flashcards popup opens showing an informational message that there is no material yet, and no AI generation call is made

### Requirement: Flashcard digenerate dari topik sesi dan catatan mention
The system SHALL generate flashcards (front/back pairs) from the conversation content of the session plus the content of notes mentioned (`@`) in the session, in Indonesian.

#### Scenario: Generate otomatis saat command
- **WHEN** user submits `/card` in a session with messages
- **THEN** the popup opens and immediately starts generating flashcards, showing a loading state until they are ready

#### Scenario: Sumber materi gabungan
- **WHEN** the session contains messages and mentions of one or more notes
- **THEN** the generation context includes both the session messages and the content of the mentioned notes

### Requirement: Pengalaman melatih flashcard interaktif
The system SHALL let the user flip each card, navigate between cards, and restart the deck, and SHALL award XP consistently with the note-based flashcards feature.

#### Scenario: Membalik dan navigasi kartu
- **WHEN** user taps a card
- **THEN** the card flips between front and back, and next/previous controls move through the deck

#### Scenario: Reward XP
- **WHEN** cards are generated from the chat and the user reviews the deck
- **THEN** the system records the same XP actions as the note-based flashcards feature (deck created, deck reviewed)

### Requirement: Kegagalan generation ditangani
The system SHALL show an error message inside the popup when generation fails, without closing the popup, and SHALL let the user retry.

#### Scenario: Generation gagal
- **WHEN** the AI fails to produce valid flashcards
- **THEN** the popup displays an error message and a retry option, and remains open

### Requirement: Flashcard mobile-friendly
The flashcards popup SHALL be fully usable on mobile viewports: rendered as a bottom sheet on small screens, with touch targets of at least 44px, respect for the safe-area inset at the bottom, and internal scrolling for long content.

#### Scenario: Popup di layar sempit
- **WHEN** the flashcards popup is open on a mobile-width viewport
- **THEN** the popup anchors to the bottom of the screen, all interactive controls are at least 44px tall, and card content scrolls within the popup without page overflow
