# Amicro components in Eureka

Sources: https://github.com/Subhan-code/Amicro--Micro-transitions-

The published `@subhanhq/amicro@1.0.1` package has no executable (`npm exec` fails).
These components were copied from the official source and adapted for Eureka:

- `MonoActivityHeatmap` (`mono-activity-purple`): real attendance, purple accent, keyboard/touch access, no randomized contributions or fixed streak.
- `MonoRoundedRadarChart` (`mono-rounded-radar`): subject journey data, responsive explicit height, no sample benchmark data.
- `DitherBook` (`dither-book`): controlled page flips, typed text/image pages, reduced motion, keyboard actions; unrelated Pinterest demo assets and intro autoplay removed.

Upstream MIT license is included. The DitherBook source retains its original Apache-2.0 notice.
