# Brand assets

`youtube-icons.png` is the original YouTube icon sheet published by Google at
https://developers.google.com/static/youtube/images/youtube-icons-2x.png
and linked in https://developers.google.com/youtube/terms/branding-guidelines.
The interface displays its red full-color icon at its original aspect ratio.

`wikipedia.png` is Wikipedia's original app icon from
https://www.wikipedia.org/static/apple-touch/wikipedia.png.
Other website icons use the source domain's real favicon, with the illustrated
source object as a fallback when the favicon is unavailable.
