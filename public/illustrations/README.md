# Study menu illustrations

`study-menu-atlas.png` is a generated, transparent 3×3 illustration atlas for
Eureka's study-room navigation. Row order: book, notebook, mindmap; quiz,
flashcards, sources; Momo chat, podcast, sticky notes.

The CSS uses equal cells at 0%, 50%, and 100% background positions. Keep the
original transparent image and its square aspect ratio when replacing it.
